АЦП и датчики Marlin

Только чтение M105: нагреватели и выходы не включаются. Открытие страницы не отправляет команд плате.

Настройка: Мои профили → Датчики, секция device_map.analog_inputs. T / T0 / B — температура; T.adc / T0.adc / B.adc — сырые отсчёты, если прошивка включает SHOW_TEMP_ADC_VALUES. ADC0 и другие ADCn доступны только при явной поддержке вашей прошивкой. Имена источников берите из ответа ниже.

Преобразование: значение = исходное × множитель + смещение. Отсчёты не являются вольтами без калибровки. Частота — частота запросов, не аппаратная частота АЦП. Во время движения и процедур монитор приостанавливается. Для записи внутри процедуры используйте шаг «Прочитать датчики».
